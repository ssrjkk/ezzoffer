# EZOffer

Копия и улучшение сервиса автооткликов на вакансии (по мотивам quick-offer.ru) — полноценное приложение на **Next.js 16 + Tailwind CSS v4 + SQLite (better-sqlite3)**.

## Возможности

### Лендинг
- Главная: Hero с бегущей лентой вакансий, «Как это работает», безопасность, истории успеха, bento-сетка преимуществ, интерактивный слайдер «до/после» резюме, тарифы с переключением периода (с активацией тарифа прямо с страницы), отзывы, FAQ-аккордеон, команда, вакансии, блог, CTA.
- Страницы: `/reviews`, `/about`, `/faq`, `/jobs` + `/jobs/[slug]`, `/pricing`, `/blog` + `/blog/[slug]`, `/login`, `/signup`, кастомная `/404`.
- SEO: metadata, sitemap.xml, robots.txt, статическая генерация (SSG) всех публичных страниц.

### Личный кабинет (`/dashboard`)
- Авторизация: регистрация/вход/выход (scrypt, httpOnly-кука `ez_session`, 30 дней), защита кабинета через `proxy.ts`.
- `Обзор` — статистика воронки (отправлено → просмотрено → ответ HR → приглашения), конверсии, лимит откликов за день, график за 7 дней, обновление каждые 5 секунд.
- `Резюме` — CRUD + «Улучшить с AI»: детект ключевых навыков по каталогу, добавление разделов, ATS-скоринг до/после.
- `Вакансии` — единый каталог с фильтрами: локальный демо-набор из `data.ts` + реальные вакансии из «Работа России» (trudvsem), «Работа.ру» и при настройке токена — hh.ru; ручной отклик, отправка резюме по email на контакты компании (кнопка «📧 По email»), внешние вакансии открываются на сайте-источнике, автопоиск (ключевые слова, уровень, формат, город, вилка, чёрный список компаний) с запуском/паузой.
- `Отклики` — таблица статусов с живым обновлением, отзыв откликов, фильтры по статусу.
- `Письма` — CRUD сопроводительных писем + шаблон.
- `Консультации` — заявки на встречу с карьерным стратегом.
- `Настройки` — профиль, пароль, тарифы и пробный период.

### Тарифы и «оплата»
- Планы: Старт (50 откликов/день), Про (100), Эксперт (250); пробный период — 24 часа.
- Оплата отключена (демо): тариф активируется мгновенно через `/api/plan`, пробный период — через `/api/trial`.

### Симуляция откликов
- Активные автопоиски «откликаются» по расписанию: цель = дни с момента старта × дневной лимит (потолок 400/поиск), отправка с естественными паузами.
- Стадии продвигаются детерминированно: просмотры (~62%), ответы HR (~52% от просмотренных), приглашения/вопросы/отказы.

### Реальный каталог вакансий
- Каталог кабинета собирается из источников: локальный демо-набор (`src/lib/data.ts`, работает всегда), «Работа России» (trudvsem, без токена), «Работа.ру» (работа.ру, парсинг JSON-LD без токена) и hh.ru (после настройки токена). Также подключаются RemoteOK, We Work Remotely, GeekJob, Jobicy, Greenhouse, RSS-фиды компаний, X/Twitter и Telegram-каналы (последние два — при наличии API-ключей).
- Внешние вакансии сохраняются в SQLite (`vacancies`) с UPSERT по слагу и обновляются кнопкой «Обновить вакансии» в кабинете (лимит: не чаще ~10 раз за 5 минут).
- Для вакансий hh.ru/trudvsem нужен токен **hh.ru**: отклики на такие вакансии ведутся в кабинете EZOffer, переход к самой вакансии — по ссылке «На сайте» на страницу источника.

## Запуск

```bash
npm install
npm run dev       # dev-сервер http://localhost:3000
npm run build     # production build
npm run start:prod # production-сервер (standalone) http://localhost:3000
npm run lint      # eslint
npm run seed      # демо-аккаунт с заполненным кабинетом (demo@ezoffer.ru / demo123)
```

> Windows: если `npm install` падает на `better-sqlite3` с ошибкой про Visual Studio —
> версия 12.11.1 уже зафиксирована в `package.json` и ставит готовый бинарник (prebuilt)
> для Node 20/22/24. Не поднимайте версию вручную до 13.x без toolchain C++.

Демо-аккаунт из `npm run seed`: тариф «Про» на 14 дней, резюме, письмо, активный автопоиск — чтобы кабинет сразу выглядел живым.

### Как включить реальные отклики на hh.ru

1. Скопируйте конфигурацию: `cp .env.example .env` (Windows: `copy .env.example .env`).
2. Создайте приложение на **dev.hh.ru** → «Мои приложения»:
   - Redirect URI: `http://localhost:3000/api/hh/callback` (для продакшена — `https://ваш-домен/api/hh/callback`);
   - отметьте права: **Отклики** (negotiations), **Чтение откликов**, **Чтение вакансий**, **Резюме**.
3. Заполните в `.env`:
   - `HH_CLIENT_ID`, `HH_CLIENT_SECRET`, `HH_REDIRECT_URI` — чтобы каждый пользователь мог подключить **свой** аккаунт кнопкой «Подключить аккаунт hh.ru» в настройках;
   - `HH_ACCESS_TOKEN` — можно указать как запасной/глобальный токен (вакансии hh.ru подгрузятся даже без OAuth).
4. Перезапустите сервер, войдите, в кабинете «Настройки» нажмите «Подключить аккаунт hh.ru» и разрешите доступ.
5. Создайте в кабинете «Резюме» резюме и «Письма» сопроводительное письмо (можно с шаблонами `{вакансия}`, `{компания}` и т.д.).
6. В разделе «Вакансии» создайте **автопоиск** (ключевые слова, город, зарплата, уровень) и нажмите «Создать и запустить».

После этого планировщик (`SCHEDULER_INTERVAL_MS`, по умолчанию каждые 5 минут) находит подходящие вакансии hh.ru и отправляет реальные отклики через API от имени вашего аккаунта, с естественными паузами между отправками (45–180 с). Кнопка «Откликнуться сейчас» на карточке вакансии hh.ru тоже отправляет отклик по-настоящему.

**Что реально поддерживает автоотклик:** только hh.ru (публичный API откликов). Остальные источники (Работа России, Работа.ру, RemoteOK, We Work Remotely, GeekJob, Jobicy, Greenhouse, RSS-фиды компаний) работают как единый каталог — отклик по ним делается кнопкой «На сайте» или через контакты компании, а в EZOffer ведётся учёт ваших откликов. Программная рассылка резюме на эти площадки невозможна без их официального API.

**Рассылка резюме по email:** если у вакансии есть контактный email (например, у «Работы России» и GeekJob), кнопка «📧 По email» отправляет ваше резюме + персонализированное сопроводительное письмо прямо на почту рекрутёра через SMTP. Это единственный честный способ «разослать резюме» на площадки без API. Для работы нужен настроенный `SMTP_*` в `.env`.

Переменные окружения:

- `SITE_URL` — публичный домен для sitemap/robots (по умолчанию `https://ezoffer.ru`).
- `HH_ACCESS_TOKEN` — токен приложения hh.ru. Без него вакансии hh.ru недоступны, trudvsem и локальный каталог работают.
- `HH_CLIENT_ID`, `HH_CLIENT_SECRET`, `HH_REDIRECT_URI` — OAuth-приложение hh.ru для подключения личного аккаунта.
- `AUTOAPPLY_*` — мягкие лимиты и рабочие часы автооткликов (см. `.env.example`).
- `AI_API_KEY` — OpenAI-совместимый ключ для улучшения резюме и персонализации писем (необязательно).
- `TELEGRAM_BOT_TOKEN` — бот для уведомлений и управления (необязательно).
- `SMTP_*` — отправка дневных отчётов на email (необязательно).

## Деплой

- Сборка `output: standalone` — `.next/standalone` можно копировать на любой сервер/VPS как есть, вместе с папкой `data/` (там живёт SQLite).
- Не подходит Vercel/Netlify: нативное `better-sqlite3` и запись файлов требуют постоянного диска.

### Docker (рекомендуется)

```bash
docker compose up -d --build   # поднимет ezoffer на :3000
```

- Образ multi-stage (`Dockerfile`): сборка → standalone, runtime — минимальный `node:24-slim` с непривилегированным пользователем.
- Данные живут в `./data:/app/data` (volume) — не пропадут при перезапуске.
- Переменные окружения (monируются в `docker-compose.yml`): `SITE_URL`, `PORT`.

> Если Docker Hub недоступен из вашей сети (TLS-таймауты), используйте зеркало: `docker pull docker.m.daocloud.io/library/node:24-slim` и замените `FROM node:24-slim` в Dockerfile.

## Структура

- `src/app` — маршруты: публичные страницы, `/dashboard/*` и API-роуты (App Router)
- `src/app/api` — REST API: auth, resumes, letters, searches, applications, stats, plan, trial, consultations, profile
- `src/components` — секции лендинга, шапка, формы и компоненты кабинета
- `src/lib` — data.ts (контент: вакансии, отзывы, FAQ, тарифы, статьи), vacancies/ (провайдеры каталога: local, trudvsem, hh + индекс/кэш), db.ts (схема SQLite), auth.ts, plans.ts, sim.ts (симуляция), resume-enhance.ts, applications.ts
- `data/` — SQLite-база `ezoffer.db` (в `.gitignore`)

## Стек

Next.js 16 (Turbopack), React 19, Tailwind CSS v4, TypeScript, better-sqlite3, ESLint.

> Платёжная система и интеграция с реальными job-платформами (hh.ru и др.) заменяются на боевые отдельно. Все данные каталога демонстрационные.
