# EZOffer

Копия и улучшение сервиса автооткликов на вакансии (по мотивам quick-offer.ru) — полноценное приложение на **Next.js 16 + Tailwind CSS v4 + SQLite (better-sqlite3)**.

## Возможности

### Лендинг
- Главная: Hero с бегущей лентой вакансий, «Как это работает», безопасность, истории успеха, bento-сетка преимуществ, интерактивный слайдер «до/после» резюме, тарифы с переключением периода (с активацией тарифа прямо с страницы), отзывы, FAQ-аккордеон, команда, вакансии, блог, CTA.
- Страницы: `/reviews`, `/about`, `/faq`, `/jobs` + `/jobs/[slug]`, `/pricing`, `/blog` + `/blog/[slug]`, `/login`, `/signup`, кастомная `/404`.
- SEO: metadata, sitemap.xml, robots.txt, статическая генерация (SSG) всех публичных страниц.

### Личный кабинет (`/dashboard`)
- Авторизация: регистрация/вход/выход (scrypt, httpOnly-кука `ez_session`, 30 дней), защита кабинета через `proxy.ts`.
- `Обзор` — статистика воронки (отправлено → просмотрено → ответ HR → приглашения), конверсии, лимит откликов за день, график за 7 дней, обновление каждые 5 секунд.
- `Резюме` — CRUD + «Улучшить с AI»: детект ключевых навыков по каталогу, добавление разделов, ATS-скоринг до/после.
- `Вакансии` — единый каталог с фильтрами: локальный демо-набор из `data.ts` + реальные вакансии из «Работа России» (trudvsem) и при настройке токена — hh.ru; ручной отклик, внешние вакансии открываются на сайте-источнике, автопоиск (ключевые слова, уровень, формат, город, вилка, чёрный список компаний) с запуском/паузой.
- `Отклики` — таблица статусов с живым обновлением, отзыв откликов, фильтры по статусу.
- `Письма` — CRUD сопроводительных писем + шаблон.
- `Консультации` — заявки на встречу с карьерным стратегом.
- `Настройки` — профиль, пароль, тарифы и пробный период.

### Тарифы и «оплата»
- Планы: Старт (50 откликов/день), Про (100), Эксперт (250); пробный период — 24 часа.
- Оплата отключена (демо): тариф активируется мгновенно через `/api/plan`, пробный период — через `/api/trial`.

### Симуляция откликов
- Активные автопоиски «откликаются» по расписанию: цель = дни с момента старта × дневной лимит (потолок 400/поиск), отправка с естественными паузами.
- Стадии продвигаются детерминированно: просмотры (~62%), ответы HR (~52% от просмотренных), приглашения/вопросы/отказы.

### Реальный каталог вакансий
- Каталог кабинета собирается из трёх источников: локальный демо-набор (`src/lib/data.ts`, работает всегда), «Работа России» (trudvsem, без токена) и hh.ru (после настройки токена).
- Внешние вакансии сохраняются в SQLite (`vacancies`) с UPSERT по слагу и обновляются кнопкой «Обновить вакансии» в кабинете (лимит: не чаще ~10 раз за 5 минут).
- Для вакансий hh.ru/trudvsem нужен токен **hh.ru**: отклики на такие вакансии ведутся в кабинете EZOffer, переход к самой вакансии — по ссылке «На сайте» на страницу источника.

## Запуск

```bash
npm install
npm run dev      # dev-сервер http://localhost:3000
npm run build    # production build
npm run start    # запуск production-сборки
npm run lint     # eslint
npm run seed     # демо-аккаунт с заполненным кабинетом (demo@ezoffer.ru / demo123)
```

Демо-аккаунт из `npm run seed`: тариф «Про» на 14 дней, резюме, письмо, активный автопоиск и ~150 откликов за 5 дней — чтобы кабинет сразу выглядел живым.

Переменные окружения:

- `SITE_URL` — публичный домен для sitemap/robots (по умолчанию `https://ezoffer.ru`).
- `HH_ACCESS_TOKEN` — токен приложения hh.ru (см. `dev.hh.ru`). Без него вакансии hh.ru недоступны, trudvsem и локальный каталог работают.

## Деплой

- Сборка `output: standalone` — `.next/standalone` можно копировать на любой сервер/VPS как есть, вместе с папкой `data/` (там живёт SQLite).
- Не подходит Vercel/Netlify: нативное `better-sqlite3` и запись файлов требуют постоянного диска.

### Docker (рекомендуется)

```bash
docker compose up -d --build   # поднимет ezoffer на :3000
```

- Образ multi-stage (`Dockerfile`): сборка → standalone, runtime — минимальный `node:24-slim` с непривилегированным пользователем.
- Данные живут в `./data:/app/data` (volume) — не пропадут при перезапуске.
- Переменные окружения (monируются в `docker-compose.yml`): `SITE_URL`, `PORT`.

> Если Docker Hub недоступен из вашей сети (TLS-таймауты), используйте зеркало: `docker pull docker.m.daocloud.io/library/node:24-slim` и замените `FROM node:24-slim` в Dockerfile.

## Структура

- `src/app` — маршруты: публичные страницы, `/dashboard/*` и API-роуты (App Router)
- `src/app/api` — REST API: auth, resumes, letters, searches, applications, stats, plan, trial, consultations, profile
- `src/components` — секции лендинга, шапка, формы и компоненты кабинета
- `src/lib` — data.ts (контент: вакансии, отзывы, FAQ, тарифы, статьи), vacancies/ (провайдеры каталога: local, trudvsem, hh + индекс/кэш), db.ts (схема SQLite), auth.ts, plans.ts, sim.ts (симуляция), resume-enhance.ts, applications.ts
- `data/` — SQLite-база `ezoffer.db` (в `.gitignore`)

## Стек

Next.js 16 (Turbopack), React 19, Tailwind CSS v4, TypeScript, better-sqlite3, ESLint.

> Платёжная система и интеграция с реальными job-платформами (hh.ru и др.) заменяются на боевые отдельно. Все данные каталога демонстрационные.
